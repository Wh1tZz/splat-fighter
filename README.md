# Splat Fighter

一款网页 1v1 格斗游戏。所有角色、动作和擂台都由 PINOC 生成，用 Viggle Splat Engine（PlayCanvas 2.18.0）实时渲染成 3D 高斯泼溅。

## 运行

双击 `start.bat`。它会启动本地服务器并自动打开浏览器（默认 http://localhost:8080 ，端口被占用时自动顺延）。

- 需要 Chrome 或 Edge（支持 WebGPU 或 WebGL2）。
- 不需要安装 Node 或 Python，服务器是 `serve.ps1`（Windows 自带 PowerShell）。
- 关掉服务器窗口即停止。

## 手机 / 平板

用手机浏览器打开网页即可，横屏游玩（竖着拿会提示把手机横过来）。选人界面右上角是「全屏」和「开始战斗」，对战中左上角也有全屏按钮；安卓 Chrome 点「开始战斗」后会自动全屏并锁定横屏。iPhone 的 Safari 不支持网页全屏：点「分享」→「添加到主屏幕」，从主屏幕图标打开即为全屏。

- 左半屏任意位置按下即出现摇杆：左右 = 前进 / 后退，上下 = 侧移绕步
- 右侧按钮：拳、踢、跳、防（按住）、闪避、必杀（槽满时发光）、技一、技二
- 组合招和键盘一样：摇杆向下 + 拳 = 技能一，摇杆向上 + 拳 = 投技，空中按拳 / 踢 = 飞踢
- 选人：点按选自己的角色，长按选对手
- 右上角 II 暂停；手机默认使用「流畅」画质
- 手机性能：场景改用精简版（每张地图保留最能代表画面的 35% 高斯，约 37 万个，下载 5 MB 而不是 16 MB）；渲染分辨率按画质封顶（高 1.5 倍、标准 1 倍、流畅 0.75 倍）；角色高斯隔帧排序。电脑上加 `?lite` 可预览精简场景，手机上加 `?full` 可强制完整场景

每个角色有 11 个单招：J、U、前进+J（冲步拳）、前进+U（冲步腿）、后退+J、后退+U，以及 4 段连招终结技等。连招路线按角色流派各不相同，最长 4 段（例如 KENJI：J J J J = 刺拳→正拳突→勾拳→双手突）。按键可以提前连按，会按顺序出招。**暂停（Esc）时显示当前角色的完整招式表**，由 `src/config.js` 里每个角色的 `combos` 表自动生成。

## 角色风格

每个角色都有一整套 PINOC 文字生成的专属动作：架势、8 个招式、必杀技、胜利动作。每个招式都从该角色自己的架势起手、打完回到同一架势，所以招式之间衔接自然。

| 角色 | 流派 | 待机架势 | 招式（J 刺拳 / J J 第 2 段 / J J J 第 3 段 / 后退+J / U / U U / 后退+U / 回旋） | 必杀技 | 胜利动作 |
| --- | --- | --- | --- | --- | --- |
| KENJI | 空手道 | 空手道组手架势：侧身、张开手刀，前手探出画圈佯攻，脚下轻弹 | 刺拳 / 正拳突 / 上勾拳式勾拳 / 上勾拳 / 前踢 / 回旋踢 / 侧踹 / 回旋后踢 | 五连拳 + 飞踢 | 鞠躬后抱臂 |
| VALERIA | 泰拳 | 高架守，有节奏地点步 | 刺拳 / 直拳 / 平肘 / 上挑肘 / 蹬踢 / 扫踢 / 飞膝 / 回旋肘 | 左右扫踢 + 高位回旋踢 | 双拳高举 |
| GRIZZLY | 重量级拳击 | 严密高架守，沉稳晃动 | 重刺拳 / 抡摆重拳 / 勾拳 / 双拳砸击 / 推踢 / 扫肋踢 / 肩撞 / 回旋背拳 | 冲锋重拳 + 跃起砸地 | 秀二头肌、捶胸 |
| SHADE | 忍者 | 正身低架，一掌前探 | 掌击 / 贯手 / 手刀 / 上挑掌 / 前踢 / 新月踢 / 侧踢 / 后空翻踢 | 掌击连打 + 旋风踢 | 抱臂结印 |

### 专属技能（每人 3 个，PINOC 文字生成动作）

| 角色 | 技能一（S+J） | 技能二（S+U） | 投技（近身 W+J） |
| --- | --- | --- | --- |
| KENJI | 烈焰气功波：火球飞行道具 | 升龙拳：起身无敌，专打跳入 | 过肩摔 |
| VALERIA | 闪电扫踢：2 米突进高扫踢 | 飞膝升天：起身无敌的飞膝 | 缠颈膝撞：锁住连续三膝 |
| GRIZZLY | 熊冲撞：2.4 米霸体冲撞，挨打不停 | 震地重拳：沿地面推进的岩刺地波 | 熊抱摔 |
| SHADE | 苦无：高速飞镖 | 瞬影斩：突进时穿过攻击的横斩 | 锁臂摔 |

- **技能取消**：普通攻击打中后可以直接接技能，例如 J J → 技能一。
- **飞行道具**：同时只能有一发；两发相撞会抵消；跳起或闪避可以躲过。
- **投技**：无视防御，专治一直按防御的对手；跳起、闪避中抓不到，抓空会有短暂破绽。
- 电脑对手会用飞行道具牵制、用突进技能贴身、对跳入用无敌技迎击、对防御中的玩家用投技。

### 必杀技（必杀槽满后按 I，或 J+U 同按）

每个角色都有一段 PINOC 生成的专属必杀动作（约 4 秒：蓄力亮相 → 连打 → 招牌终结技 → 收势定格），配完整演出：

1. **发动**：擂台压暗（只暗场景，角色保持亮度），角色立绘与招式名的切入横幅扫过屏幕，镜头推到正面特写。
2. **蓄力**：动作到蓄力姿势时时间冻结约 0.7 秒，能量从四周汇入身体。发动到第一击之前**无敌**。
3. **连打**：第一击命中即**锁定**对手，后续每一下必中；全身发出角色色光环、高斯残影和加粗拳脚拖尾。第一击落空则整套作废，露出大破绽。
4. **终结**：画面瞬间变为高反差负片（动漫式冲击帧）+ 长定格 + 专属终结特效。

| 角色 | 必杀 | 终结特效 |
| --- | --- | --- |
| KENJI | 红莲千本突 CRIMSON THOUSAND FISTS | 火柱从地面喷发 |
| VALERIA | 紫电·雷霆飞肘 VIOLET THUNDER ELBOW | 腾空飞肘 + 天降落雷 |
| GRIZZLY | 熊王·裂地击 URSA EARTHBREAKER | 双拳砸地，多重冲击环与碎石 |
| SHADE | 霓影·千刃斩 NEON PHANTOM BLADE | 横贯全屏的斩光 + 高斯分身 |

跳跃攻击也各不相同（K 起跳后在空中按 J 或 U）：KENJI 飞身侧踹、VALERIA 泰拳飞膝、GRIZZLY 跃起踏踢、SHADE 旋风踢，命中都会击倒对手。

受击和倒地也换成了 PINOC 生成的动作：打脸后仰、打腹弯腰、重击踉跄、上勾拳击飞。终结一击触发处决演出：定格、0.2 倍慢镜头、镜头跟着倒地的身体环绕；被打倒的一方按击中部位旋转扑倒，或被击飞倒地。

## 高斯能力展示点

1. **选人显形**：角色沿骨骼从脚到头扫描成形（引擎 `setReveal`）。
2. **自由视角**：战斗中随时拖动 360° 查看任何角度。
3. **连招慢镜头**：第 3 段连击命中时 0.25 倍速并环绕特写。
4. **打击反馈**：3D 空间中的命中火花（带重力、落地反弹）、命中光芒与放射光刺、透视贴地冲击环、拳脚光带拖尾、镜头视野冲击与倾斜，以及擂台地面扩散的高斯冲击波（`Environment.setShock`）。技能的火球、苦无、地裂和岩石喷发也是同一套发光风格。
5. **残影只用在关键处**：闪避留 2 个高斯副本，SHADE 必杀终结时出 3 个分身；普通重击和必杀过程不再出残影。
6. **KO**：慢镜头击倒后，败者从脚到头消散成光点，下一局重新显形。
7. **必杀技**：PINOC 文字生成的三连拳 + 回旋踢，带专属运镜。
8. **拍照模式 + 画质对比**：右下角实时显示高斯数量与帧率。

| 地图 | 场景 |
| --- | --- |
| 地下拳场 | 废弃仓库里的地下格斗场，铁丝网与工业吊灯 |
| 紫禁城·太和殿 | 黄昏的太和殿广场，背后是汉白玉台阶与红墙金瓦 |
| 罗马斗兽场 | 沙地竞技场，四周是层层石拱看台 |
| 九龙霓虹街 | 雨后的香港街道，湿地面倒映满街霓虹招牌 |

三张新地图用 PINOC 的高质量全景档（`quality: high`）生成，远景比默认档清晰。画面按屏幕实际像素密度渲染（高画质最多 2 倍），高分屏上不会再被拉伸模糊。每张场景载入时自动探测地面深度换算成米（九龙的湿路面会骗过探测，用固定值）；`src/config.js` 的 `STAGES` 里 `yaw` 决定战斗线朝向哪一面风景。新增地图：把 `.spz` 放进 `assets/env/`，在 `STAGES` 里加一行。

## 画质与老机型

选人界面「画质」三档，游戏中按 **Q** 循环切换，选择会被记住：

| 档位 | 每个角色 | 渲染分辨率 | 特效 |
| --- | --- | --- | --- |
| 高 | 48,000 高斯 | 100% | 全部 |
| 标准 | 16,000 高斯 | 100% | 全部 |
| 流畅（老机型） | 16,000 高斯 | 70% | 粒子 40%、无烟雾、无必杀残影、残影副本 2 个 |

- 首次打开自动判断：不支持 WebGPU（走 WebGL2）、CPU ≤ 4 核或内存 ≤ 4 GB 的设备默认「流畅」，否则「高」。
- 战斗中帧率连续 5 秒低于 30，自动降一档并提示。
- 打击感主要靠骨骼层面的效果（命中时出击肢体拉长的"拖影帧"、重击时躯干压扁、必杀蓄力时胸臂膨胀），每次只需约 0.5 ms，老机型同样有效。
- 调试参数：`?webgl` 强制走 WebGL2（模拟不支持 WebGPU 的机器），`?nocull` 关闭点云视锥剔除。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `src/main.js` | 启动加载、选人、回合流程、命中判定、慢镜头、HUD |
| `src/fighter.js` | 角色状态机、招式、连招、受击、残影 |
| `src/ai.js` | 电脑对手（入门 / 普通 / 高手） |
| `src/camera.js` | 格斗镜头、自由旋转、特写运镜 |
| `src/fx.js` | 命中火花、闪屏、擂台冲击波、必杀终结特效 |
| `src/input.js` | 键盘与手柄 |
| `src/config.js` | 角色数值、招式帧数据、平衡参数 |

每个招式在载入时都会自动测量：拳、脚、肘、膝在哪一帧、以多大的转身角度能真正碰到对手身体，以及最远能打多远（`main.js` 的 `measureStrike`）。战斗中身体只做最小的转向让拳脚落在对手身上；对手略在距离外时会在起手阶段小步贴近；只有真正挥动中的关节碰到对手才算命中。调整手感改 `src/config.js` 里的 `MOVES` 和 `TUNING`。更换了 `assets/motions/` 里的动作文件后，把 `main.js` 的 `MOTION_VERSION` 加 1，避免浏览器缓存旧文件。

## 已知限制

- 玩家在网页里上传照片自助生成角色还没做：需要 PINOC 提供线上服务器可调用的接口。目前新角色由 Claude 通过 PINOC MCP 生成后放进 `assets/characters/`，再在 `src/config.js` 的 `ROSTER` 里登记。
- 没有手机触屏按键。
- `@viggle/splat-engine` 0.2.0 依赖 PlayCanvas 2.18.0 内部实现，两者版本都已固定在 `vendor/`，不要单独升级。
